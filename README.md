# Godwin Mbah

Personal site of GodwinXbt. Smart contract auditor at SMC Audits. Researcher first. Builder second.

Live: [godwinxbt.vercel.app](https://godwinxbt.vercel.app)

## What this site is

- Findings with working PoCs or independently traced root causes
- Live tools for approvals, tokenized-stock checks, and payment settlement
- A public record of the method: mechanism over narrative

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Content lives in `app/lib/findings.ts` and `app/lib/work.ts`.

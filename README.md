# GodwinXbt

Personal site. Engineer, protocol researcher, security as a method.

Live: [godwinxbt.vercel.app](https://godwinxbt.vercel.app)

## What this site is

- Work across payments, infrastructure, protocols, and research
- Findings with working PoCs or independently traced root causes
- A public record of the method: mechanism over narrative

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Content lives in `app/lib/projects.ts` and `app/lib/findings.ts`.
